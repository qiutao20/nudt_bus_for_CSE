# 班车最近一班

这是一个小网页，用来查各上车点最近能坐上的班车。

当前上车点：宿舍、系统楼、东门、北门、军体、高超北侧、二食堂（去往研究生宿舍）、二食堂（去往系统楼）。

已纳入：

* 环线1路
* 环线2路（观光车）
* 就餐专线
* 线路 2 / 5 / 7 / 8

环线2路（观光车）与普通线路2是两条不同线路。

支持：

* 按当前时间查询
* 手动填写日期时间查询

## 规则

* 周一至周四：环线1路 + 环线2路（观光车）+ 就餐专线 + 线路 2 / 5 / 7 / 8
* 周五：环线1路 + 环线2路（观光车）+ 就餐专线 + 线路 2 / 5 / 7 / 8
* 周六：环线2路（观光车）+ 线路 2 / 8
* 周日：环线2路（观光车）+ 线路 8
* 法定节假日统一采用周日运行表；调休上班日统一采用周一至周四运行表
* 2026 年采用国务院正式安排；2027 年采用中国货币网预设日期，待国务院正式通知发布后更新调休日期
