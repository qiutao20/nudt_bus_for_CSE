# 班车最近一班

这是一个小网页，用来查宿舍或学院最近能坐上的班车。

已纳入：

* 环线
* 环线3路(观光车)
* 就餐专线 v2
* 线路 2 / 5 / 7 / 8

支持：

* 按当前时间查询
* 手动填写日期时间查询

## 规则

* 周一至周四：环线 + 就餐专线 v2 + 线路 2 / 5 / 7 / 8
* 周五：环线 + 就餐专线 v2 + 线路 2 / 5 / 7 / 8
* 周六：环线3路(观光车) + 线路 2 / 8
* 周日：环线3路(观光车) + 线路 8
* 2026 年法定节假日：在对应周几运行表基础上增加环线3路(观光车)

## 人为推算偏移

* 线路 2：佳园到宿舍 20 分钟，宿舍到学院 8 分钟
* 线路 5：景园到宿舍 15 分钟，宿舍到学院 8 分钟
* 线路 7：四号院到宿舍 40 分钟，宿舍到学院 8 分钟
* 线路 8：一号院到宿舍 25 分钟，宿舍到学院 8 分钟
* 环线班车：宿舍发车后 7 分钟到学院
* 环线3路(观光车)：宿舍发车后 5 分钟到学院，学院发车后 7 分钟到宿舍
* 就餐专线 v2：学院始发，仅在学院上车点显示
