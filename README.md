# 班车最近一班

这是一个小网页，用来查各上车点最近能坐上的班车。

当前上车点：宿舍、系统楼、东门、北门、军体、激光所、高超北侧、理学院、二食堂（去往研究生宿舍）、二食堂（去往系统楼）。

已纳入：

* 环线1路
* 环线2路（原环线3路）
* 就餐专线
* 线路 2 / 5 / 7 / 8

环线2路与普通线路2是两条不同线路。

支持：

* 按当前时间查询
* 手动填写日期时间查询

## 规则

* 周一至周四：环线1路 + 环线2路 + 就餐专线 + 线路 2 / 5 / 7 / 8
* 周五：环线1路 + 环线2路 + 就餐专线 + 线路 2 / 5 / 7 / 8
* 周六：线路 2 / 8
* 周日：线路 8

## 人为推算偏移

* 线路 2：佳园到宿舍 20 分钟，宿舍到系统楼 8 分钟
* 线路 5：景园到宿舍 15 分钟，宿舍到系统楼 8 分钟
* 线路 7：四号院到宿舍 40 分钟，宿舍到系统楼 8 分钟
* 线路 8：一号院到宿舍 25 分钟，宿舍到系统楼 8 分钟
* 环线1路：宿舍发车后 7 分钟到系统楼
* 环线2路：宿舍始发，3 分钟到二食堂（去往系统楼），6 分钟到激光所，10 分钟到系统楼
* 就餐专线：系统楼始发，可在系统楼、理学院和二食堂上车点显示

## 开发版新增站点数据

* 新增站点顺序按车辆实际行驶路线排列。
* 高超北侧对应环线1路经过系统楼一侧的站点。
* 新增站点偏移统一使用四舍五入后的整数分钟；既有宿舍、系统楼的偏移保持不变，避免影响线上用户已经使用的查询结果。
